# Keep cleared dashboard logs empty when new events arrive

## Problem

The stream hook stores activity and console rows both in atoms and in private refs. Clear actions empty the atoms, but the next websocket message appends to the old ref and restores the cleared rows.

## Changes

Update the current atom values directly. Keep command/result replacement and the 500-row limit. Add a regression that delivers messages to the production hook using a controlled transport and a real Jotai store, then clears each log and delivers another message. The existing dashboard CI build runs the test.
