# Reload dashboard activity when a session reconnects on a new port

Upstream pull request: [#2496](https://github.com/vercel-labs/agent-browser/pull/2496)

Status: open; merged: false.

## Problem

Persisted activity is restored only when the session name changes. A restarted daemon can keep that name and get a new stream port. Once live stream rows reset, the old restored prefix can replace the more recent persisted history. A render captured before a session switch can also write its rows under the new session's key.

## Changes

Associate restored rows with both the session name and port, reload them for a new daemon port, and save only history belonging to the current selection. Add a regression using the production hook, controlled effects, and a real Jotai store. The dashboard build runs the test in CI.
