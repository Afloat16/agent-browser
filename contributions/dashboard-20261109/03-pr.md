# Report malformed dashboard command responses as errors

## Problem

A response can fail while its JSON body is decoded after fetch resolves. The command and kill helpers returned that promise directly, so their catch blocks did not handle these failures. HTTP failures and malformed result objects could also reach callers as successful command responses.

## Changes

Await body decoding, validate the expected result fields, preserve useful server errors, and turn unsuccessful HTTP responses into failed results. Add six regression cases and run dashboard tests before the dashboard build so the existing CI job executes them.
