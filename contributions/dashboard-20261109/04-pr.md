# Read dashboard storage values from command response envelopes

Upstream pull request: [#2498](https://github.com/vercel-labs/agent-browser/pull/2498)

Status: open; merged: false.

## Problem

The storage panel reads cookie and Web Storage values from fields outside the CLI response's data envelope. Valid results therefore appear empty or show response metadata as storage keys. Cookies sharing a name and domain also collide when their paths differ.

## Changes

Decode data.cookies and data.data through checked helpers, retain a stored key named length, and identify cookie rows by domain, path, and name. Add five regression cases and run dashboard tests before the existing CI build.
