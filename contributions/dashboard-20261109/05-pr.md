# Keep stale storage requests from replacing the active session data

Upstream pull request: [#2499](https://github.com/vercel-labs/agent-browser/pull/2499)

Status: open; merged: false.

## Problem

A storage response can arrive after the user selects another session or storage tab. The old request then writes its values into the active panel and can clear the loading indicator while the current request is still pending.

## Changes

Route storage reads through a request generation that owns both result and completion callbacks. Invalidate that generation when the panel changes scope or unmounts, and reset values when the active session disappears. Add deferred-response tests for stale results, cleanup, and current-request failures. The existing dashboard CI build runs these tests.
