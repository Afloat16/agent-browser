# Allow retrying dashboard session closes after a failure

Upstream pull request: [#2500](https://github.com/vercel-labs/agent-browser/pull/2500)

Status: open; merged: false.

## Problem

Close and kill actions mark a session as closing and discard its chat before the request completes. If the request fails, the closing marker remains, so the session cannot be retried and its chat has already been lost. Bulk close follows the same path.

## Changes

Use one asynchronous stop action, discard chat after success, and remove the closing marker after a failed or rejected request. Keep successful sessions marked until polling confirms their removal. Add a regression against the production action atoms using a real Jotai store and deferred transport results.
