# Stop overlapping dashboard session polls and cancel them on cleanup

Upstream pull request: [#2502](https://github.com/vercel-labs/agent-browser/pull/2502)

Status: open; merged: false.

## Problem

The session poll uses a fixed interval even when the previous session or tab request is still pending. Slow requests can overlap and apply results out of order. Unmounting clears the interval but leaves its active fetches able to update shared session state.

## Changes

Schedule the next poll after the current session and tab requests finish. Pass an AbortSignal to those requests, abort them during cleanup, and reject late results even if the transport completes after cancellation. Add a regression with deferred fetches, controlled timers, and the production hook's real Jotai store.
