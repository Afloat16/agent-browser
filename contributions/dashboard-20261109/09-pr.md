# Discard stale dashboard frames and release decoded image bitmaps

## Problem

Frame decoding is asynchronous. An obsolete frame can finish after a newer frame or after the viewport effect is cleaned up and overwrite the canvas. Decode failures also reject without a handler, and a draw failure can skip bitmap cleanup.

## Changes

Give every frame effect a cancellation callback, draw only while that effect is current, and close decoded bitmaps in a finally block. Add regression cases for successful drawing, cleanup during decoding, and rejected decodes. The dashboard build runs the tests in CI.
